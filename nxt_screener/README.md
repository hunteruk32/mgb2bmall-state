# 2일 연속 대량거래 양봉 스크리너 (1단계: KRX 정규장)

## 하는 일
1. **스크리닝**: 직전 2거래일 연속으로 `종가 > 시가(정규장)` 이면서 일 거래대금이 3,000억 원 이상인 종목을 찾습니다.
2. **Envelope(20, 12.5%)**: 상단 이탈과 밴드워킹 일수, 중심선 눌림목, 하단 이탈을 판정합니다.
3. **수급**: 신호 2일간 외국인·기관(투신, 연기금) 순매수 금액과 거래대금 대비 비중을 계산합니다.
4. **3일차 리스크 점검**: 전일 신호 종목을 오늘 기준으로 점검합니다.
   - 상단 10% 이상 이탈 후 음봉이면 차익실현 경계
   - 거래대금 급감(직전 2일 평균의 50% 이하)과 긴 윗꼬리가 함께 나오면 비중 조절 검토

## 실행 (본인 PC)
```bash
pip install -r requirements.txt
# KRX 정보데이터시스템(data.krx.co.kr) 무료 회원 계정 필요
export KRX_ID=아이디      # Windows: set KRX_ID=아이디
export KRX_PW=비밀번호    # Windows: set KRX_PW=비밀번호
python screener.py                     # 최근 거래일 기준 (16시 이전 실행 시 전일 기준)
python screener.py --date 20261030     # 특정일 기준
python screener.py --min-value 2000    # 거래대금 기준 변경 (억 원)
```
결과는 화면에 출력되고 `output/screen_YYYYMMDD.csv`로 저장됩니다. 엑셀에서 열어도 한글이 깨지지 않습니다.

## 데이터 출처
- 모든 숫자는 실행할 때 KRX와 네이버(수정주가)에서 가져온 실제 데이터입니다. 코드 안에 시세가 들어 있지 않습니다.
- `test_screener.py`의 숫자는 로직 검증용 가짜 데이터이며, 실제 실행에는 쓰이지 않습니다.

## 한계 (2단계 예정)
- 거래대금은 KRX 정규장 기준이며 NXT 거래분은 빠져 있습니다.
- NXT 괴리율, NXT 거래 비중, 프리마켓 갭은 키움 REST API 연동 후 추가할 예정입니다.
