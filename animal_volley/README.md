# 동물 배구 🏐

블루투스로 친구 폰과 1:1로 붙는 비치발리볼 게임 (안드로이드, Flutter).

## 캐릭터
벌꿀오소리 · 돼지 · 킹콩 · 바다사자. 동물마다 색이 4가지 있어요.
두 사람이 같은 동물을 고르면 색으로 구분해요. 같은 동물·같은 색은 고를 수 없어요.
캐릭터는 이미지 파일 없이 코드로 직접 그려요(`lib/game/characters.dart`).

## 모드
- **블루투스 대전**: 한 명이 [방 만들기], 다른 한 명이 [방 찾기]를 눌러 연결해요.
  인터넷 없이 근처 기기끼리 연결돼요(Google Nearby Connections: 블루투스/BLE, 가능하면 Wi-Fi Direct).
- **CPU와 연습**: 상대 없이 혼자 할 수 있어요. 난이도는 쉬움/보통/어려움이에요.
- **서브 연습**: 상대 없이 공이 계속 내 머리 위로 올라와요. 네트 너머로 넘기면 성공이고,
  성공 수·성공률·연속 성공·최고 연속 기록이 표시돼요(메뉴에서 기록 초기화).

## 환경설정
- **공 속도 / 캐릭터 이동 속도**: ×0.6 ~ ×1.6. 공 궤적은 그대로 두고 빠르기만 바뀌어요.
  블루투스 대전에서는 호스트의 설정이 두 사람 모두에게 적용돼요.
- **배경음악 / 효과음 음량**

## 소리
효과음 13가지와 배경음악 2곡(메뉴, 경기)은 모두 `tools/make_audio.py`로 직접 합성·작곡했어요.
소리를 바꾸려면 스크립트를 고친 뒤 `python3 tools/make_audio.py`를 실행하세요(numpy, ffmpeg 필요).

## 조작
| 버튼 | 동작 |
|---|---|
| ◀ ▶ | 이동 |
| 점프 | 점프 |
| 스파이크 (공중) | 기본: 내리꽂기 · 앞으로 누른 채: 직선 강타 · 뒤로 누른 채: 페인트 |
| 스파이크 (땅, 방향과 함께) | 다이빙 |

키보드: ← → 이동, ↑ 점프, 스페이스/Z 스파이크

먼저 15점을 내면 이겨요.

## 구조
```
lib/
  game/world.dart          물리·규칙 (순수 Dart, 테스트 있음)
  game/cpu.dart            CPU 상대
  game/characters.dart     캐릭터·공 그리기
  game/court_painter.dart  경기장 그리기
  net/session.dart         블루투스 연결·메시지
  audio.dart               효과음·배경음악 재생
  settings.dart            환경설정(기기에 저장)
  ui/                      화면들 (타이틀, 로비, 캐릭터 선택, 경기, 터치 버튼)
  dev/preview.dart         캐릭터 시안 확인용 화면 (개발용)
test/world_test.dart       게임 로직 테스트
tools/make_audio.py        효과음·배경음악 합성 스크립트
assets/audio/              합성된 소리 파일(.ogg)
```

블루투스 대전에서는 방을 만든 쪽(호스트)이 물리를 계산해서 약 30Hz로 상태를 보내요.
게스트는 버튼 입력만 보내고, 받은 상태 사이를 자체 예측으로 메워서 부드럽게 보여줘요.

## 빌드
```bash
flutter test
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```
지금 APK는 디버그 키로 서명돼 있어요. 플레이스토어에 올리려면 별도의 서명 키가 필요해요.
iOS는 지원하지 않아요(Nearby Connections 플러그인이 안드로이드 전용이에요).
